**LATEST VERSION : Finsler-Lagrange Geometry of Far-from-Equilibrium Thermodynamics**

(presently submitted to Physical Review E.)

▪ Used Lagrange Spaces(not to be confused with Lagrangian Mechanics) to create a framework for non-equilibrium systems valid at arbitrary distance from      equilibrium

▪ Lagrangian allows for asymmetry in velocities (due to non linear odd terms) which basically represents dissipative anisotropy. We dont use finsler spaces  here because they'd restrict entropy production to be 2 homogenous in fluxes

▪ Used a infinite dimensional field space (internal energy density and particle number density) to actually be able to model systems that aren't uniform

▪ Second order system to capture inertial/non-instantenous effects

▪ Evolution is represented by a forced geodesic (which can essentially represent any path on the manifold). Since our framework must recover Onsager's       framework, the extra term is very strongly constraint

▪ Showed how attempting to absorb the semispray coefficients and the forcing term into a new modified semispray coefficient creates a second order system that is not derivable from another seperate Lagrangian with the help of the helmholtz conditions and metrizibility conditions (same thing)

▪ But the new modified semispray still serves an important purpose; it allows one to use kosambi-cartan-chern (KCC) theory to perform a jacobi analysis of   trajectories, as for a given second order system you can still define geometric objects like non-linear connections

▪ KCC theory is vital to the framework. Using the modified connection and semispray, we derive a modified deviation tensor. If the deviation tensor is       negative at some region of the manifold it implies nearby trajectories diverge, which explains why thermodynamic systems with near similar initial           conditions do not take similar path towards equilibrium. Some form unique dissipative structures, some may take other routes. It also explains the chaotic,  highly sensitive behaviour of non-equilibrium systems.
If instead, in a region the deviation is positive, it would imply nearby trajectories converge, which explains why some paths are very stable to             perturbations, which potentially be linked to the adaptive behaviour of far-from-equilibrium systems. Bifurcation is then explained by when a system does    trajectory moves from a region where the deviation tensor is negative to where it is positive, moving from displaying chaotic highly sensitive behaviour to  behaving like a stable system.

▪ Onsager is recovered using a taylor expansion near the zero section. The first and second term vanish due to positive definiteness (as we defined) of the  Lagrangian in velocities, leaving only the quadratic term which simplifies to a riemannian structure.

▪ In order to actually use the framework one needs to specify the entropy functional and the Lagrangian functional. 

▪ In essence, the Lagrangian encodes how the underlying medium influences the process, including effects such as mobility, dissipation, coupling, and non-linear response. Different choices of L therefore correspond to different transport characteristics of the medium. For example, a Lagrangian containing strongly non-linear terms associated with the internal energy density but weakly non-linear terms involving the particle number density may correspond to a medium exhibiting a stronger nonlinear thermal transport response than particle transport response.

▪ The framework at present accounts for completely dissipative non stochastic processes. But it could naturally be extended to include both dissipative and stochastic processes via the inclusion of a momentum density and a probability density field on the state-space.
